## PHASE 1 (Year 1) — Foundations. "Bina base ke building nahi banti."
Goal: Python + math + basic ML aa jaye.
- **Months 1-3: Python solid.** Roz code. (freeCodeCamp / Python docs). Numpy zaroor.
- **Months 4-6: Math for AI.** Linear algebra (3Blue1Brown), phir probability, phir calculus basics. (Khan Academy / MIT OCW)
- **Months 7-9: ML basics.** Andrew Ng ML course. Har algorithm KHUD numpy mein likho.
- **Months 10-12: First projects.** 3-4 chhote ML projects (classifier, regression). GitHub par daalo.
Milestone: numpy mein ek neural network scratch se likh sako.

## PHASE 2 (Year 2) — Deep Learning + Reasoning basics.
- Deep learning (fast.ai / deeplearning.ai). PyTorch seekho.
- CNNs, RNNs, phir **Transformers** ("Attention Is All You Need" — hamari library file 01).
- Reproduce ek chhota paper (koi bhi simple result).
- ARC-AGI se dosti: hamare RAKSHANEX repo ko dobara padho, samjho, extend karo.
Milestone: ek transformer scratch se train kar sako; ek paper reproduce.

## PHASE 3 (Year 3) — Specialize in REASONING / AGI-core.
- Padho (hamari library files 02-12): AGI surveys, ARC, reasoning models, safety.
- Program synthesis + DreamCoder (library learning) — deeply.
- ARC Prize har saal try karo (chhota, better hota jaayega).
- Neural + symbolic dono samjho (VSA, CompressARC padho).
Milestone: ARC-AGI par apna ek naya idea implement + test karo (0-wrong wala nahi, coverage wala).

## PHASE 4 (Years 4-5) — Real research contributions.
- Ek narrow open problem chuno (jaise "sample-efficient generalization" ya "safe reasoning").
- Chhote experiments → arXiv preprints likho (jaise humne RAKSHANEX paper banaya).
- Open-source sab. Community mein active (ARC Prize Discord, X/Twitter research).
- Ek workshop paper submit karne ka target (NeurIPS/ICML workshops accept beginners).
Milestone: 1-2 real preprints/workshop papers apne naam par.

## PHASE 5 (Years 6-7) — Depth + collaboration.
- Kisi ek sub-field mein "known" bano (jaise ARC reasoning, ya interpretability).
- Doosre researchers ke saath collaborate (co-author).
- Bade experiments (tab tak GPU access — Kaggle/Colab free, ya cloud credits).
- Optionally: MSc/research role ke liye apply (agar formal path chahiye).
Milestone: ek accepted conference/workshop paper; ek collaboration.

## PHASE 6 (Years 8-10) — Original AGI contribution.
- Ek genuinely hard, under-explored AGI problem par saalon-lamba kaam.
- Apna research agenda (blog/papers se define karo).
- Tab tak aap ek real researcher ho — job/PhD/startup/lab, jo aap chaho.
Milestone: ek recognized original contribution to the field.

## DAILY RHYTHM (roz ka 1 ghanta)
- **40 min:** aaj ka topic seekho / paper padho (ek section, poora nahi — chhota par roz)
- **20 min:** us par KUCH code likho / experiment karo (chhota bhi chalega)
- Har hafte: 30 min extra — hafte ka summary likho (ek notebook/journal maintain karo)

## WEEKLY / MONTHLY
- Har hafte: 1 chhota output (code, note, ya solved problem)
- Har mahine: 1 chhota project ya paper-reproduction, GitHub par
- Har saal: ARC Prize / ek competition + apni progress review

## RULES (sabse zaroori)
1. **Consistency > sab kuch.** 1 hr roz > 7 hr ek din.
2. **Karke seekho**, sirf padhkar nahi. Har concept ka chhota code.
3. **Public raho** — GitHub, notes share karo (jaise RAKSHANEX). Credibility banti hai.
4. **Honest raho** — jo samajh na aaye, maano; jo kaam na kare, document karo. (Negative results bhi research hain.)
5. **Basics par zyada time** (Year 1-2). Log yahi skip karte hain aur atak jaate hain.
